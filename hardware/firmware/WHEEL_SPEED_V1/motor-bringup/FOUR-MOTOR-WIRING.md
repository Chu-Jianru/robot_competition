# 四路接线规划（D24A V1.1 + ESP32-WROOM-32）

2026-10-27 最新方向复测：用户纠正 B/C 的正输出朝车尾，A/D 正常。固件已仅反转 B/C，A/B/C/D 电气极性均为 -1；轮位保持 CBAD、面板方向保持全 +1。修正需烧录，所有 GPIO 接线不变。

2026-10-27 最新轮位：A 左后、D 右后、C 左前、B 右前，即 FL/FR/RL/RR=CBAD。用户确认四路正输出都朝车头，方向继续全 +1，通道电气引脚和驱动极性不变。以下 10 月 22 日的轮位记载为历史，不再作为当前安装位置。

2026-10-22 装车实测补充：通道位置为 A 左前、B 左后、C 右后、D 右前。原电气正输出 A/D 朝后、B/C 朝前，现由 MECANUM_V2 底层驱动固化修正；麦克纳姆布局使用 ADBC、全 +1。JOG/WHEELS/MECANUM 均使用正数向前，不能在面板再次取反。下表电气引脚没有改变。

更新日期：2026-10-20。下表是用户最终确认的接线，已实现为 FOUR_V1 四路固件，并成功烧录到 COM4。实机已验证四路静止查询、面板通道选择及 DRY_RUN 输出隔离；未发送真实电机运行指令。STBY 沿用 GPIO13。

IN 引脚调速方式保持：四个 PWM 输入固定接 D24A 自身 5V，ESP32 对各路 IN1/IN2 输出 PWM。沿用此前用户选择的 3.3V 直接控制试验，尚未证明满足 TB6612 在 5V 逻辑供电下的高电平规格。

## 适配状态

固件按上表初始化四组 IN1/IN2 PWM 和四组编码器 CHANGE 中断。上电默认模拟模式，STBY 关闭，全部 8 个 PWM 输出为零。真实台架选择一路点动，停止或通信超时关闭所有通道。

GPIO34/35 用作 D 路编码器输入。16 个信号引脚无重复，全部避开启动配置脚 GPIO0/2/5/12/15；STBY 的 GPIO13 不与任何信号重复。

旧 A 路控制 GPIO25/26 的固件已作废，这两个脚现在是 C 路编码器输入。新面板连接必须核对 FOUR_V1 引脚版本，避免用旧程序测试新接线。

四路计数、标定和记录已分开；真实运动、编码器正负号和每圈计数仍需后续逐路现场确认。

- D24A STBY → ESP32 GPIO13，共用一根线，不固定接高电平。
- D24A PWMA、PWMB、PWMC、PWMD → D24A 自身 5V 输出，可分别使用四个 5V 排针。
- ESP32 GND → D24A GND，电池负极 → D24A 电源负极；电池正极 → Vin+。保持原已验证的 6V 供电，四电机带载供电能力需后续单独测试。
- ESP32 仍由 USB 供电；D24A 的 5V、3V3 输出不接 ESP32 电源脚。编码器沿用 D24A 电机口 3V3/GND 供电，反馈信号不可为 5V。
- GPIO16/17 在部分板上标为 RX2/TX2；不能接成 USB 串口 RX0/TX0。GPIO34/35 仅输入、无内部上下拉，可用作编码器输入，不能用作电机输出。
- 电机同款且六针线序相同时，分别插入对应 Motor_A/B/C/D 口；电机接插口编号不自动对应车身位置。底盘确定后再记录各路前后左右及方向符号。
