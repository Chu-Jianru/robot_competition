# 本车 FOUR_V2 接线

按当前固件及 2026-11-16 实车回读核对。详细引脚、极性与布局统一见 [本车固件说明](../../README.md)，对应源码为 `src/motor_profile.h` 与 `src/main.cpp`。

- A 路 IN1/IN2/EA/EB 为 `22/23/21/19`。
- B 路 IN1/IN2/EA/EB 为 `17/18/16/4`。
- C 路 IN1/IN2/EA/EB 为 `26/25/27/14`。
- D 路 IN1/IN2/EA/EB 为 `32/33/35/34`。
- STBY 为 GPIO13。GPIO34/35 用作输入，外部上拉及编码器电平按实物电路核对。

逻辑前进的电气极性 A/B/C/D 为 `+1/-1/-1/+1`，由底层统一转换一次。当前菜单布局 `CBDA 1 1 1 1` 按左前、右前、左后、右后排列。

[接线表](../../../ESP32与D24A当前接线表.xlsx) 为保留资料，旧 FOUR_V1 编号可在 [vendor 原始包](../../../../vendor/README.md) 追溯。车体与编码器方向验收按 [现场手册](../../../../docs/手机接入与自主清扫手册.md) 执行。
