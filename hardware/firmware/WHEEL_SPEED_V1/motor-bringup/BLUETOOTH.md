# Windows 蓝牙连接

ESP32 使用内置经典蓝牙 SPP，设备名 `PushRobot-ESP32`。当前本机曾使用蓝牙传出 COM6、USB COM3，端口以 Windows 实际分配为准。

1. 给 ESP32 供电，在 Windows 蓝牙设置中添加设备。要求 PIN 时使用 `271038`。
2. 在“更多蓝牙设置 → COM 端口”中找该设备的传出端口。
3. 打开 [日常工具](../../../../tools/日常工具.cmd)，菜单 9 连接底盘，按 [现场手册](../../../../docs/手机接入与自主清扫手册.md) 核对轮位与标定。
4. 当前菜单使用 CBDA 轮位和 FOUR_V2 固件配置，详见 [本车固件](../../README.md)。

USB 与蓝牙通过独占控制权访问同一固件。切换前先停车并断开现有控制器，再连接新端口；控制端保持心跳，超时或蓝牙断开时固件停车并撤销控制权。机械滑行距离须按实车验证。

`PermissionError` 表示端口访问失败。检查其他工作台、任务或遥控窗口的串口占用，按手册排查蓝牙旧连接。连接状态与当前烧录记录见 [交接说明](../../../../交接说明.md)。
