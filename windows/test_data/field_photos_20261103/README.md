## 手动标注

双击 `windows/标注场地照片.cmd`，或在批处理命令末尾加 `--annotate`。该模式只看静态图片，不自动启动。按图中的**可见红块**逐块点中心；紧挨的块分别点，车轮不点，被遮挡且无法确定的块不猜测。

- `B`：红块中心模式，左键添加，右键撤销最后一个点。
- `K`：场地地面内四角模式，沿周边顺时针或逆时针连续点四角，起点不限。点地面和围栏相接处，**不要点围栏上沿**。程序按蓝黄颜色定方向；相机换视角后逐图标，不共用标定。四点满后右键撤销再修正。
- `C/F`：保留的可选人工参考功能，当前无需使用（tag 已近似居中、对齐车头）。本批只需用 `B/K` 标红块和地面四角，不用手动标 tag。
- `V`：当前图已核对；`S`：保存；`N/P`：下一张/上一张并保存；`Q/Esc`：保存退出。后续增删标注会取消该图已核对状态。

结果保存到此目录 `annotations.json`，坐标始终是原图像素。再次运行批处理会显示手动红块标记，并用已点齐的四角替代自动四角生成离线候选；严格检测数量仍单独保留为原算法基线。人工点不是算法输入的红块真值，不能靠标注宣称算法检出成功。

优先标 01（粘连）、05（车旁/场外红块）、10/11/13（tag 漏检和轮子干扰）；最终需逐张标注可见红块才能定量评估。
