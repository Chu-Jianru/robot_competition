# 常用命令

现场操作、菜单编号与快捷键见 [手机接入与自主清扫手册](手机接入与自主清扫手册.md)。双击 [日常工具](../tools/日常工具.cmd) 打开菜单；菜单本身只显示配置状态。

## PowerShell 环境

在新终端设置以下变量。所有命令从项目根目录执行。

```powershell
Set-Location 'E:\robot_competition'
$robotScrcpy = 'E:\scrcpy\scrcpy-win64-v5.0.1'
$robotPython = Join-Path $robotScrcpy '.venv\Scripts\python.exe'
$robotSession = Get-Date -Format 'yyyyMMdd_HHmmss'
$robotCaptureDir = Join-Path $PWD "windows\captures_hi\$robotSession"
$robotCalib = Join-Path $PWD 'windows\field_calib.json'
```

## 手机与取图

检查 USB 识别与授权，手机应显示为 `device`。

```powershell
& '.\tools\日常工具.cmd' --check-phone
```

仅看 scrcpy 后置摄像头画面。

```powershell
& "$robotScrcpy\scrcpy.exe" --video-source=camera --camera-facing=back --max-size=1280 --camera-fps=30 --no-audio
```

使用项目取流拍照并标定，按 S 保存、点四个地面内角、Enter 确认。Q 从照片回到视频，Esc 从视频退出。启动前关闭其他取图窗口。

```powershell
& $robotPython .\windows\capture_hi.py --scrcpy-dir $robotScrcpy --rotate 90 --max-size 1280 --no-fallback --out $robotCaptureDir --calibrate-out $robotCalib
```

台架识别使用同一命令加 `--bench`，按场地标定看位姿加 `--config $robotCalib`。更换机位、分辨率、旋转或变焦后重新标定。

连续帧诊断会实际启动相机，将判决、统计与可选原图保存到 `windows/captures_hi/diag_时间/`。场地标定存在时采用场地模式，否则采用台架模式；`--track` 记录块级稳定结果，`--show` 打开显示。

```powershell
& $robotPython .\windows\record_diag.py --scrcpy-dir $robotScrcpy --secs 15 --save-frames
```

## 策略与底盘

菜单 9 为轮速标定，11 为车体运动标定，12 为视觉/策略预览，10 为自主清扫，13 为遥控。运动入口的前置条件与端口核对见 [操作手册](手机接入与自主清扫手册.md)。

手动调用预览，采用与菜单相同的画面方向。

```powershell
& $robotPython .\windows\run_task.py --preview --scrcpy-dir $robotScrcpy --rotate 90 --max-size 1280
```

预览会打开相机。B/Y 选择己方，空格开始策略计时，Q/Esc 退出。`--detector hsv` 可切回 HSV，`--onnx-device cpu` 可指定 CPU，`--obstacles` / `--no-obstacles` 显式指定障碍检测。

完整工作台由 `tools/启动新面板.cmd` 打开。`tools/核对固件版本.cmd` 比较电脑源码与原始 zip。固件编译与烧录统一见 [工具说明](../tools/README.md)。

## 照片批处理

带车照片可将输入改为 `field_photos_20261103`，并去掉 `--expect-no-robot`。以下每条命令按先后执行。

```powershell
$robotBatchDir = '.\windows\test_data\field_no_robot_20261103'
$robotResultDir = ".\log\daily_runs\$robotSession\no_robot"
& $robotPython .\windows\detect_field_batch.py --input $robotBatchDir --output $robotResultDir --expect-no-robot
& $robotPython .\windows\evaluate_field_batch.py --predictions "$robotResultDir\detections.json" --input $robotBatchDir --output "$robotResultDir\evaluation"
Invoke-Item "$robotResultDir\detections_contact.jpg"
Invoke-Item "$robotResultDir\evaluation\errors_contact.jpg"
```

该批处理遍历 JPG，使用批次自己的 `annotations.json` 四角；`--ignore-labels` 可单独检查自动边界。候选数与人工确认物块数分别记录。照片标注用 `windows/标注场地照片.cmd`、`windows/标注无车场地照片.cmd`，框选训练数据见 [训练说明](../training/README.md)。

单张已标定原图的位姿检查使用 `pose_tag.py <图片路径> --config $robotCalib`。

## 离线检查

以下测试使用照片、合成输入与假串口。

```powershell
& $robotPython -B -m unittest discover -s windows -p 'test_*.py'
```

只显示日常菜单或检查某个入口生成的命令。

```powershell
& $robotPython -B .\windows\daily_tools.py --list
& $robotPython -B .\windows\daily_tools.py --action task-preview --dry-run
```

训练、导出和 HSV/ONNX 对比统一见 [训练说明](../training/README.md)。ROS 仿真命令见 [策略设计](自主策略设计.md)，h15 保持暂停。
