# 手机接入与自主清扫手册

Windows 上使用 Mate60 Pro 通过 USB 取图，小车通过蓝牙接收指令。在 PowerShell 运行下列命令，输入菜单编号并按回车。菜单用青色标记开始、绿色标记结束、黄色标记取消、红色标记未完成。 [项目里的手机接入流程.ps1](../tools/手机接入流程.ps1)

```powershell
& "$env:LOCALAPPDATA\RobotCompetition\手机接入流程.ps1"
```

这是本机的启动脚本，菜单仍读取 E 盘项目。用 PowerShell 7 时，也可以直接从 E 盘运行项目里的脚本。加 `-Check` 只查 USB，加 `-Daily` 可打开包含离线工具的完整菜单。

- 单独调手机识别走 **8 → 1 → 2**，需要统计再选 **3**。小车可以断电。
- 首次跑整车走 **1 → 4 → 11 → 12 → 10**。底盘参数还没测时，可以先做 **12**，把视觉和策略调通。
- 配置齐全后，每次走 **8 → 1 → 10**。需要复查策略时，在 **10** 之前先用 **12**。

## 接上线后单独调手机识别

1. **检查 USB。** 手机保持解锁，使用「传输文件」并开启 USB 调试。如果弹出「允许 USB 调试」，在手机上确认。运行接入脚本会先查一次，选 **8** 可以重查。看到 Mate60 Pro 对应的 `ALN-AL00` 和状态 `device`，或脚本提示「USB 通过」，表示电脑已连上 ADB。
2. **选 1 看原始画面。** 先退出手机相机 App 和电脑上其他取图窗口。打开取图后等控制台显示「首帧到达」。让后置镜头看向光线充足、有物体的地方，可以在镜头前移动一张纸确认画面会跟着变化。窗口顶部显示分辨率、处理帧率和帧龄。按 **S** 拍原图，控制台会打印保存路径。默认保存在 `windows/captures_hi/`，文件名形如 `hi_时间_宽x高.png`。按 **Q / Esc** 退出，再打开下一项。
3. **选 2 检查车顶 tag 和红块。** 把车顶 ID 7 标记与一两个红块放进画面，保持 tag 无遮挡、少反光。这一步可以在桌面做。看标记能否被稳定框出，控制台是否显示 tag 像素边长和红块候选数量。若显示 `tag: not found`，先确认对焦、照明和标记大小。台架红块计数用于看识别是否工作，整场分割和归属在 **12** 查看。看完按 **Q / Esc**。
4. **可选 3 统计 60 帧。** 保持相机和标记位置固定，等待终端打印检出率、处理帧率和帧龄。默认 tag 检出率门槛为 95%，结果保存到终端打印的 `windows/captures_hi/live_时间/` 目录。看终端的「通过／未通过」，退出码只表示工具是否正常运行。画面停滞时先解决取流，必要时按 **Ctrl+C** 结束统计。

收到一帧就能确认数据流接通。整车任务还要用连续的新帧判断车和红块的位置，正式启动前用 **12** 核对。

## 首次配置场地

1. **选 1 拍全场原图。** 固定手机后置镜头，让蓝区在画面下方、黄区在上方，四个地面内角都入镜并留一点边距。菜单按 90° 旋转、1280 档取流，这台 Mate60 Pro 实测为 960×1280。画面方向不合适时调整手机安装方向，保持脚本默认设置。若用 **R** 临时旋转过，退出再选 **1** 恢复默认方向。画面清晰后按 **S**，记下文件路径，再按 **Q**。以前用 1920 档拍图或标定过，需要在新尺寸下重拍原图并重新点四角。
2. **选 4 点场地四角。** 选择刚保存的 `hi_时间_宽x高.png` 原图。依次点击**画面左上 → 右上 → 右下 → 左下**的地面内角，沿地板内边找交点。右键撤销最近一个点，四点正确后按 **Enter** 保存，按 **Esc** 取消。检查随后打开的校正图，确认场地铺满方形画面、蓝区在下、黄区在上。按任意键关闭校正图。标定存入 `windows/field_calib.json`。
3. **可选 5 检查位姿。** 放入带 ID 7 标记的小车，看校正窗口能否稳定显示 tag 框、车头箭头和 `x / y / h`。手动移动车辆后，坐标应跟随，箭头应朝实际车头。按 **Q / Esc** 退出。换机位、变焦、旋转或分辨率后，重新走 **1 → 4**。

## 首次录入底盘参数

1. 在 Windows 蓝牙设置的 COM 端口页查 ESP32 的**传出**端口。以前用过 COM6，重新配对可能换号。核对车上的四路接线和正转方向，按**左前、右前、左后、右后**记录对应通道，四个字母连写。历史记录同时出现过 ADBC 和 CBAD，按本车实物核对。
2. 如果已有本车实测数据，直接进 **11**。如需测量，选 **9** 打开工作台，在空地测试并随时准备停车。连接正确串口，在「麦克纳姆控制」页核对并应用实物轮位，确认「轮速闭环」未勾选，持续时间填 **0.10 秒**。分别单独点动前进、左移、逆时针，等待停稳后记录距离或角度，并留出固件冷却时间。工作台的「停止全部 / Esc」可请求停车。测量和轮位未确认前，可以继续做 **12** 的无底盘预览。
3. **选 11**，按提示输入 COM 口、轮位、前进换算、左移换算、逆时针换算、已验证的单轮输出上限（任务入口接受 **1–40%**）。三个换算值分别用停稳后的距离（mm）或转角（°）除以指令百分数，再除以 **0.10 秒**。例如某次前进使用 30%，实测停稳后前进 9 mm，则前进换算值为 `9 / 30 / 0.10 = 3`。按本车实测结果填写。设置保存在 `windows/task_drive.json`。

## 策略预览和正式任务

1. **摆起跑位。** 车头朝黄区，车停稳，车顶 tag 清晰可见。把车心放在蓝区距蓝黄中线约 **25–50 cm**、距左右地面内边各至少 **12 cm** 的空位，避免贴墙。
2. **选 12 预览。** 看校正画面里蓝黄分界线、车顶 tag 框和红块轮廓是否对应实物。看到 **PREVIEW | SPACE to start policy** 后，按空格看策略阶段。预览只计算策略，底盘保持静止。按 **Q / Esc** 退出预览。
3. **选 10 发车。** 底盘上电，先断开并关闭调试面板释放 COM 口。关闭其他取图窗口。等待任务窗口显示 **SPACE to start**，点一下窗口让它获得焦点，再按**空格**开始 90 秒任务。也可用独立启动器打开任务窗口。 [启动自主清扫.cmd](../tools/启动自主清扫.cmd)
4. **结束或急停。** 按 **Q / Esc** 或关闭任务窗口，程序会请求停车并释放相机和蓝牙。90 秒到时、定位丢失、画面超过 0.35 秒或链路失效也会结束本轮。故障排除后重新摆车并启动。

## 遇到提示时

- **空列表、unauthorized 或 offline**。先解锁手机，检查调试授权、数据线与 USB 口。需要时拔插数据线，回到脚本选 **8** 重查。
- **Windows 显示「未知 USB 设备（设定地址失败）」Code 43**。先恢复 Windows 对手机的 USB 识别，再继续 ADB 和相机。保持同一手机，换已确认可传数据的线或另一个电脑 USB 口，一次只换一项。
- **黑屏、画面卡住或 waiting for newer frames**。检查后置镜头朝向、光线、支架遮挡和手机上是否有相机 App 在使用镜头。关闭其余取图客户端，再选 **1**，确认画面连续变化后再启动。
- **field seam missing、frame size differs 或 ID 7 未定位**。确认完整场地、黄上蓝下以及镜头方向。清理车顶 tag 遮挡和反光。如果换过机位或画面尺寸，重新走 **1 → 4**。
- **place robot in blue start zone, facing yellow**。把车摆回蓝区起跑位，车头朝黄区，放稳后等到空格提示。
- **waiting for Bluetooth、串口无法打开或轮位回读不符**。核对底盘供电、蓝牙传出端口和调试面板的串口占用。先确认本车实际轮位，再用 **11** 修正配置。

仅检查 USB 时可在 PowerShell 执行：

```powershell
& "$env:LOCALAPPDATA\RobotCompetition\手机接入流程.ps1" -Check
```

更多参数见 [Windows 视觉与任务说明](../windows/README.md)。
