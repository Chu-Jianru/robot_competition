# 手机接入与自主清扫手册

Windows 上使用 Mate60 Pro 通过 USB 取图，小车通过蓝牙接收指令。双击 [日常工具.cmd](../tools/日常工具.cmd)，输入菜单编号并按回车。直接按回车可以再次查看菜单和配置状态。选中取图、预览或任务后，程序会先检查手机 USB 授权和 scrcpy 通道占用。若提示「已清理上次取图留下的 scrcpy 通道」，说明上次取图异常退出留了空转发，程序已自行删除，继续即可；只有确实还开着取图窗口时才会提示「手机已有 scrcpy 通道」。

- 单独调手机识别走 **8 → 1 → 2**。小车可以断电。
- 首次跑整车走 **1 拍照并标定 → 11 → 12 → 10**。底盘参数还没测时，可以先做 **12**，检查视觉和策略。
- 配置齐全后，每次走 **8 → 1 → 10**。需要复查策略时，在 **10** 之前先用 **12**。

## 接上线后单独调手机识别

1. **选 8 检查 USB。** 手机保持解锁，使用「传输文件」并开启 USB 调试。如果弹出「允许 USB 调试」，在手机上确认。成功时只显示一行绿色提示「USB 通过，已找到一台已授权手机。」失败时按红色提示排查。
2. **选 1 看原始画面。** 先退出手机相机 App 和电脑上其他取图窗口。打开取图后等控制台显示「首帧到达」。可以在镜头前移动一张纸确认画面会跟着变化。窗口顶部显示分辨率、处理帧率和帧龄。按 **S** 拍原图并停在照片上，照片保存在 `windows/captures_hi/`。按 **Q** 从照片回到实时视频，按 **Esc** 从视频返回菜单。
3. **选 2 检查车顶 tag 和红块。** 把车顶 ID 7 标记与一两个红块放进画面，保持 tag 无遮挡、少反光。这一步可以在桌面做。看标记能否被稳定框出，控制台是否显示 tag 像素边长和红块候选数量。若显示 `tag: not found`，先确认对焦、照明和标记大小。台架红块计数用于看识别是否工作，整场分割和归属在 **12** 查看。看完按 **Q / Esc**。

收到一帧就能确认数据流接通。整车任务还要用连续的新帧判断车和红块的位置，正式启动前用 **12** 核对。

## 首次配置场地

1. **选 1，按 S 拍全场原图。** 固定手机后置镜头，让四个地面内角都入镜并留一点边距。原图里蓝黄可以左右排列。菜单使用与任务相同的画面方向和 1280 档取流，这台 Mate60 Pro 实测为 960×1280。画面清晰后按 **S**，窗口会切到刚拍的原图。
2. **在照片上点四角。** 沿地板内边找四个交点，左键按任意顺序各点一次，右键撤销最近的点。看到确认蓝黄分界线的提示后按 **Enter**，标定会保存到 `windows/field_calib.json`，并显示黄上蓝下的方形校正图。照片或校正图中按 **Q** 回到视频，视频中按 **Esc** 回到菜单。
3. **可选 5 检查位姿。** 放入带 ID 7 标记的小车，看校正窗口能否稳定显示 tag 框、车头箭头和 `x / y / h`。手动移动车辆后，坐标应跟随，箭头应朝实际车头。按 **Q / Esc** 退出。换机位、变焦、旋转或分辨率后，用 **1** 重拍并标定。

## 首次自动标定底盘

1. ESP32 固件须支持 `CHASSIS_SPEED_STREAM`，并已有有效轮速标定。程序会自动检查。如果固件报告缺少轮速标定，或第一次运动报 `FAULT encoder_sign`，用 **9** 打开轮速标定窗口。先把四轮架空，核对端口和轮位，点击「连接」。出现「轮位已确认」后勾选架空确认，点击「开始标定」。标定会用到 100% 输出。看到「标定已保存」后断开并关闭窗口。 [轮速标定说明](../hardware/firmware/WHEEL_SPEED_V1/motor-bringup/CLOSED-LOOP-VERIFICATION.md)
2. 固定手机，完成场地四角标定，清空场地并将车放在中心，保持车顶 tag 可见。关闭其他取图窗口和底盘工作台。**选 11**，核对蓝牙传出端口（本车先前是 COM6）和实际轮位（本车遥控默认 CBDA，顺序为左前、右前、左后、右后）。
3. 窗口显示 `READY` 后按**空格**。车会自动前后、左右平移和双向转动，每个方向测三次。标定以固件速度流上限的约三分之一移动，减少画面延迟和滑行造成的超量。相机检测位移和航向，并用 50 mm 黑框修正车顶平面尺度。ESP32 在每段前后读取四轮计数。确认重复结果一致后自动保存 `windows/task_drive.json`，其中任务的 `max_wheel_counts_per_s` 取固件速度流上限。按 **Q / Esc** 可停车退出。取消或失败时保留已有配置。旧版 PWM 参数需要改用本步骤重新标定。

菜单 **11** 在空场标定。开始前移走红块、对方机器人和其他物品。

## 键盘遥控

关闭占用串口的底盘工作台或任务窗口，选 **13**。按回车或选 **1** 启动轮速闭环，选 **2** 启动直接 PWM。默认用 **COM6** 和本车轮位 **CBDA**（左前、右前、左后、右后）。点击遥控窗口，再用 **W/S** 前进或后退、**A/D** 左转或右转、**Q/E** 左移或右移。串口或轮位更换后，可以用 `keyboard_drive.py --port ... --layout ...` 指定，直接启动 PWM 模式时加 `--pwm`。

窗口标题显示当前模式。轮速闭环与菜单 10 共用 ESP32 的 `SPEED_STREAM`，启动时回读轮速上限和四轮编码器标定符号。若提示缺少有效的轮速标定，先用菜单 **9** 架空四轮完成标定并保存。直接 PWM 使用 `MECANUM_MANUAL`，窗口显示的百分比就是设定占空比，最高 **100%**。

新按下的方向键优先，松开它会回到仍按住的上一个方向。轻点一次会短暂移动约 **0.10 秒**，长按后松键会请求停车。下一次动作会等停车回执后下发。**Z/X** 每次增减 5 个百分点，范围 **5–100%**，初始 **80%**。轮速闭环按本车轮速上限换算目标，直接 PWM 用于设置占空比。

**空格**停车，**Esc** 停车并退出，切出遥控窗口也会请求停车。ESP32 的轮速指令每次最多有效 150 毫秒，直接 PWM 指令为 250 毫秒，有效期耗尽会停车。

选 **13** 会同时打开「遥控检测」窗口，画面与 **10/12** 相同：场地蓝黄分界线、车顶 ID 7 边框、红块轮廓与归属（绿=己方、橙=对方）、策略跟踪到的蓝框障碍；顶行显示己方半区、红块数、tag 边长、障碍数和帧龄。检测在后台线程用与任务相同的取流、红块模型和场地标定，画面方向也相同（菜单传 `--rotate 90`，与标定的 960×1280 一致）。键盘按键始终发给遥控窗口；点一下检测窗口会把焦点还给遥控窗口，关闭它只停检测和相机，不影响遥控。检测依赖手机 USB 和场地标定，取流或标定不可用时窗口不出现，控制台会说明原因，遥控仍可单独使用（不加 `--camera` 也能只开遥控窗口）。

## 障碍（对方车体）检测开关

菜单 **14** 切换，当前状态显示在菜单第一行，保存在 `windows/detection_flags.json`；菜单 **10/11/12/13** 在下次启动时按这个开关运行，改开关不影响已经开着的窗口。

**默认开启。** 菜单 **10/12/13** 在检测画面用蓝框标出障碍。菜单 **10/12** 的策略优先选择可绕行的路线，找不到时允许接触对方车体。菜单 **11** 在空场标定时确认近车障碍。关掉开关后，这些入口跳过障碍检测。红块、tag 与场地分界照常显示。

## 策略预览和正式任务

1. **摆起跑位。** 车可以从场内任意位置和朝向起步，车要停稳，车顶 tag 清晰可见。规划器从当前位姿找有净空的接近和转向路线。
2. **选 12 预览。** 检查蓝黄分界、车顶 tag 和红块轮廓。亮紫色框标出己方 tag，箭头指向车头。按 **B** 选蓝方或 **Y** 选黄方，默认以车所在半区为己方。看到 `SPACE start` 后按空格。画面用青色显示接近及退出路线，橙色显示推送段。预览只计算策略，按 **Q / Esc** 退出。
3. **选 10 发车。** 底盘上电，关闭占用串口或相机的其他工具。窗口显示正确的己方颜色和 `SPACE start` 后按**空格**，锁定己方并开始 90 秒计时。策略先比较横推线路，把尽可能多的己方红块送到侧墙附近，再按当前画面沿墙推过中线。随后优先清理红块较多、较集中的可达集群，每铲结束后根据新画面重新规划。 [启动自主清扫.cmd](../tools/启动自主清扫.cmd)
4. **结束或急停。** 按 **Q / Esc** 或关闭任务窗口，程序会请求停车并释放相机和蓝牙。90 秒到时、定位丢失、画面超过 0.35 秒或链路失效也会结束本轮。故障排除后重新摆车并启动。

## 遇到提示时

- **未检测到手机、未授权或离线**。先解锁手机，检查调试授权、数据线与 USB 口。需要时拔插数据线，回到菜单选 **8** 重查。
- **Windows 显示「未知 USB 设备（设定地址失败）」Code 43**。先恢复 Windows 对手机的 USB 识别，再继续 ADB 和相机。保持同一手机，换已确认可传数据的线或另一个电脑 USB 口，一次只换一项。
- **黑屏、画面卡住或 waiting for newer frames**。检查后置镜头朝向、光线、支架遮挡和手机上是否有相机 App 在使用镜头。关闭其余取图客户端，再选 **1**，确认画面连续变化后再启动。
- **field seam missing、frame size differs 或 ID 7 未定位**。确认场地完整入镜、校正图黄上蓝下，原图和任务使用同一画面方向。清理车顶 tag 遮挡和反光。如果换过机位或画面尺寸，用 **1** 重拍并标定。
- **`STOPPED stream_timeout`**。底盘 150 ms 内没收到新的速度流。菜单 **11** 用最新有效画面的时限续期；首次起步前会等编码器快照之后的新帧。如果仍出现，检查画面是否停帧、蓝牙是否掉线、串口是否被底盘工作台占用。也可以改用 ESP32 的 USB 串口做蓝牙排除测试。用 USB 标定时，保存的 `task_drive.json` 会记录 USB 端口，跑 10 前要把 `port` 改回蓝牙传出端口（如 COM6）。
- **`STOPPED link_timeout`**。底盘在 1.5 秒内没有收到能续期的命令，已撤销控制权并停车。速度流在停车和读取编码器期间仍会发 `PING` 保活。若更新后仍然出现，检查蓝牙连接和底盘供电，恢复后将车放回场地中心重新运行 **11**。
- **`FAULT no_feedback`**。某路轮子的目标与实测轮速持续不符，ESP32 已执行保护停车。新版固件的故障行带 `WHEEL`、`TARGET`、`MEASURED`、`PWM`。按故障轮检查机械卡阻、驱动供电和编码器接线。目标与实测轮速单位为计数/秒，`PWM` 为占空比百分数。
- **`11` 提示视觉帧龄过高**。程序立即请求停车，等新画面和车辆停稳再继续本段。持续 2 秒无可用新位姿则退出，控制台会保留最近的帧龄、取帧等待和视觉处理耗时。
- **`11` 提示某段验算失败**。把完整失败行留存。比较触发停车和停稳后的位置可判断是否冲过目标。tag 投影边长变化过大时检查手机支架、地面四角和 tag 是否平贴。沿指令方向计数非正时，根据日志的 A/B/C/D 原始增量、标定符号和 FL/FR/RL/RR 轮位核对编码器。
- **`11` 提示起步前或停车后等待超时**。按该段日志检查画面、tag 稳定性、障碍候选或蓝牙状态。若提示预计行程超出标定活动范围，退出后把车放回场地中心，再从第一段开始。
- **`11` 显示 `Clear the field`**。检查场地里的红块与蓝框内已确认的近车障碍。若因障碍退出，控制台会打印 `log/drive_calibration/` 内的排查图路径，`_boxed.png` 标出蓝框，`_input.png` 是同帧识别输入。
- **place robot inside the surveyed field**。让车顶 tag 位于标定场地内，车停稳后等到空格提示。车放在对方半区时，发车前用 B 或 Y 明确选择己方颜色。
- **`10` 暂停发车或清扫**。`HOLD: policy stop` 表示策略输出了零速度，`HOLD: motion safety` 表示运动安全检查拦下了指令，`HOLD: frame timing` 表示画面时限不足。菜单 **12** 可静止查看蓝框障碍和预览路线。
- **`13` 检测窗口一直是「正在等待手机画面」或黑屏**。先看窗口中间写的等待秒数和命令行的停止原因。常见原因是画面方向与场地标定不一致（标定是 960×1280），这时不要用 `--rotate auto`，按标定方向传 `--rotate 90`；换过机位或分辨率则用 **1** 重拍标定。手机没授权、被其它取图窗口占用或停帧时也会一直等待，按上一条排查。
- **waiting for Bluetooth、串口无法打开或轮位回读不符**。核对底盘供电、蓝牙传出端口和调试面板的串口占用。先确认本车实际轮位，再用 **11** 修正配置。报 `PermissionError` / 「拒绝访问」时是 COM6 被占用或旧蓝牙串口链路没释放：关掉底盘工作台、轮速面板和任务/遥控窗口，给 ESP32 断电重上，在 Windows 蓝牙里断开后重新连接；ESP32 插着 USB 时先拔掉只留蓝牙。
- **`9` 开始轮速标定后设备应答超时**。先看诊断日志最后一条 `CAL` 回包。如果蓝牙在转轮时断开，可以用 ESP32 的 USB 数据线连接电脑，仍在 **9** 里选 CP210x 对应的端口（本机通常为 COM3）。保持四轮架空和车载电池供电。只有看到「标定已保存」才继续 **11**。

在 PowerShell 中仅检查 USB：

```powershell
& 'E:\robot_competition\tools\日常工具.cmd' --check-phone
```
